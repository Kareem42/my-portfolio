## Quick Start

Prerequisites:
- Node.js 16+ (Node 18+ recommended)
- npm or yarn

1. Install dependencies

```bash
npm install
# or
# yarn
```

2. Run the dev server

```bash
npm run dev
# or
# yarn dev
```

Open http://localhost:5173 in your browser to preview.

3. Build for production

```bash
npm run build
# or
# yarn build
```

4. Preview the production build locally

```bash
npm run preview
# or
# yarn preview
```

## Typical NPM scripts

Your package.json may include these scripts (common in Vite projects):


Adjust them to match what's in your package.json if needed.

## Project structure

A typical structure for this starter:

```
my-portfolio/
├─ public/            # static assets
├─ src/
│  ├─ assets/         # images, icons, fonts
│  ├─ components/     # reusable UI components
│  ├─ pages/          # page-level components or routes
│  ├─ styles/         # global styles, variables
│  └─ main.jsx        # app entry
├─ index.html
├─ package.json
└─ vite.config.js
```

## Deployment

Pick any of the following quick options:

- Vercel: Connect the repo and deploy (Vite builds automatically). No extra config required in most cases.
- Netlify: Drag & drop or connect the repo. Build command: `npm run build`, Publish directory: `dist`.
- GitHub Pages: Use `gh-pages` or a custom workflow to publish `dist/`.

---

## Customization

- Edit `src/main.jsx` or `src/App.jsx` (or equivalent) to change your site's content and routes.
- Replace the contents of `public/` and `src/assets/` with your own images and icons.
- Update metadata in `index.html` (title, description, social preview tags).
